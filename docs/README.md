operational history so useful evidence is not confused with instructions.

## Historical evidence, not instructions

- Root guides other than `README.md`, `AGENTS.md`, and `CLAUDE.md` describe frozen v1 incidents,
  migrations, styling, deployment, or superseded product directions. Each must carry a visible
  frozen/superseded banner.
- `status/`, `system-dossier/`, `ui-status/`, `audit.md`, `KNOWN_BUGS.md`, and the repository
  `benchmarks/` folder audit the retired root application unless a file explicitly says otherwise.
- [`../v2/BRIEF.md`](../v2/BRIEF.md), [`../v2/DIRECTION.md`](../v2/DIRECTION.md),
  [`../v2/FRIENDS.md`](../v2/FRIENDS.md), and [`../v2/ROADMAP.md`](../v2/ROADMAP.md) preserve earlier
  v2 pivots. They are not backlog authority.
- [`../v2/docs/READS.md`](../v2/docs/READS.md) and [`../v2/functions/`](../v2/functions/) preserve
  the retired public friend-graph security proposal and TONIGHT-hours backend. Neither is active.

Run `npm run docs:check` after adding or renaming any root Markdown document. It refuses
unclassified root guides, unlabeled nested v1 audits, and unlabeled historical v2 strategy or
backend files.
